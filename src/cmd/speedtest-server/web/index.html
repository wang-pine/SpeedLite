测速结果

链路方向平均峰值总传输 交付损失抖动用时时间

TCP 使用有序 stop/result 建立共同统计边界，双端字节偏差 <1% 才算正常。UDP 显示 WebRTC 应用层「交付损失」，并把提交、排空、接收和队列残留分开；它不是 IP 层 UDP 丢包率。网页无法精确测抖动，精确丢包/抖动请用命令行 speedctl udp。

历史记录

    命令行精确测速（speedctl）

    网页的 WebSocket / WebRTC 受浏览器协议栈开销影响，极限数值请用原生 socket 客户端：

    speedctl -s 服务器IP tcp up -P 4 -t 10
speedctl -s 服务器IP tcp down -P 4 -t 10
speedctl -s 服务器IP udp up -P 1 -l 60000 -t 10
speedctl -s 服务器IP udp down -P 1 -l 60000 -t 10
